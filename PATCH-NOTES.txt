KAELHAX Admin Mobile/UI V18

1. Admin mobile navigation is now a slide-out sidebar with hamburger button and backdrop.
2. Admin sidebar closes automatically when a tab is selected or when viewport becomes desktop.
3. Product editor is full-width on phones instead of squeezing fields beside the thumbnail.
4. Product pricing rows stack cleanly on small screens.
5. Storefront checks the Firebase users/{uid} document after authentication and redirects enabled admin accounts directly to /admin.
6. Existing Firebase auth/profile and Firestore role checks are preserved.
7. No Firebase console/rules changes are required for the UI/redirect changes.
